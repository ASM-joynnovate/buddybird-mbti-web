# 05 · 풀숲 전환 애니메이션

Status: ready-for-agent

## Parent

`.scratch/parrot-mbti/PRD.md`

## What to build

문항 전환 시 **"풀숲을 헤치고 이동하는" 애니메이션**을 04 문항 페이지에 입힌다.
풀숲의 시각 룩(에셋 스타일·색)은 03 디자인 게이트를 따르고, 이 슬라이스는 그 룩을
구동하는 **모션 동작**을 구현한다.

확정된 모션 사양:

- **트리거**: 선택지를 골라 다음 문항으로 자동 전환되는 순간.
- **연출 = 갈라짐 + 전진(parting + push-through)**: 풀잎/이파리 벡터 실루엣이 양옆으로 갈라지면서, 동시에 콘텐츠가 살짝 앞으로 나아가는(전진) 느낌을 준다.
- **풀숲 형태 = 일러스트/벡터 실루엣**(실사 아님). 가벼운 단색/실루엣 레이어로 처리한다.
- **강도 = 가장자리만 스치는 가벼운 액센트**: 화면을 가득 덮지 않는다. 좌우(또는 가장자리)에서만 풀잎이 잠깐 스치고 갈라지는 정도로, 짧게 끝난다. 자동 진행의 빠른 호흡을 방해하지 않아야 한다.
- 사운드/햅틱은 포함하지 않는다.
- **컴포지터 친화 속성만 사용**한다(`transform`/`opacity`/`clip-path`). 레이아웃 유발 속성(width/height/top/left/margin 등) 금지.
- `prefers-reduced-motion` 시 즉시 전환으로 대체한다.
- 전환 중에도 자동 진행/직전 문항 이동 등 04의 동작이 깨지지 않아야 한다.

## Acceptance criteria

- [ ] 문항 전환 시 벡터 실루엣 풀잎이 양옆으로 갈라지며 콘텐츠가 전진하는 모션이 재생된다.
- [ ] 모션이 화면을 덮지 않고 가장자리만 스치는 가벼운 액센트로, 자동 진행 호흡을 방해하지 않을 만큼 짧다.
- [ ] 풀숲 룩이 03 디자인 게이트의 스타일/색을 따른다.
- [ ] 모션이 컴포지터 친화 속성만 사용한다(레이아웃 유발 속성 없음).
- [ ] `prefers-reduced-motion`에서 즉시 전환으로 폴백된다.
- [ ] 전환이 04의 자동 진행/되돌아가기 동작을 깨뜨리지 않는다.
- [ ] 시각 스크린샷으로 전환 상태가 확인된다(reduced-motion 포함).
