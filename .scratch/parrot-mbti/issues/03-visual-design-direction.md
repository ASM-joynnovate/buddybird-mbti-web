# 03 · 비주얼 디자인 방향 & 시스템

Status: ready-for-human

## Parent

## What to build

앵무새 MBTI 웹 전체의 **비주얼 디자인 방향과 디자인 시스템**을 확정한다.
이 슬라이스는 **모든 UI/UX 구현 슬라이스(04·05·06·07·08·09·13)의 선행 게이트**이며,
일관된 디자인 패턴을 보장하기 위한 단일 기준점이다.

- 스타일 방향을 구체적으로 선택한다(템플릿 느낌 회피 — anti-template). 모바일 우선, 바이럴/공유에 어울리는 톤.
- 디자인 토큰을 정의한다: 팔레트, 타이포(쌍 전략), 간격 리듬, 라운드/그림자, 모션 듀레이션·이징.
- **"풀숲을 헤치고 이동하는" 문항 전환 모션 언어**의 방향을 정의한다(컴포지터 친화 속성 전제, reduced-motion 폴백 포함).
- 핵심 surface의 비주얼 방향을 정한다: 안내 캐러셀, 문항 카드/선택지, 결과 리포트, **결과 카드(인스타 공유용, 1080×1080)** 템플릿 룩.
- 재사용 가능한 UI 프리미티브(버튼, 선택지, 카드, 진행률 등)의 시각 규칙을 확립한다.

산출물은 디자인 토큰과 공용 UI 프리미티브로 코드화하고, 이후 UI 슬라이스가 이를 준수한다.

## Acceptance criteria

- [ ] 명시적 스타일 방향 1개가 선택되고 근거가 기록된다(막연한 "clean minimal" 금지).
- [ ] 팔레트·타이포·간격·라운드/그림자·모션의 디자인 토큰이 정의된다.
- [ ] "풀숲" 전환 모션 언어의 방향과 reduced-motion 폴백 원칙이 명시된다.
- [ ] 안내/문항/결과/결과 카드의 비주얼 방향이 시안 또는 스타일 가이드로 확정된다.
- [ ] 공용 UI 프리미티브(버튼·선택지·카드·진행률)가 토큰 기반으로 코드화된다.
- [ ] 사람(디자인) 리뷰 승인.
