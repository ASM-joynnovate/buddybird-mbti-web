# 04 · 문항 페이지

Status: ready-for-agent

## Parent

`.scratch/parrot-mbti/PRD.md`

## What to build

실제 12문항을 진행하는 **문항(Test) 페이지**. 디자인 시스템(03)을 준수해 구현한다.
전환 애니메이션은 05에서 별도로 입힌다(여기서는 기본 전환).

- 한 번에 1문항 + 2선택지만 노출한다.
- 선택지를 고르면 **별도 "다음" 버튼 없이 자동으로 다음 문항으로 전환**한다.
- 현재 진행률(예: 4/12)을 표시한다.
- 직전 문항으로 되돌아가 답을 수정할 수 있다.
- 마지막 문항 답안 직후 결과 페이지로 자동 이동한다.
- 진행 중 새로고침 시 동작을 명시적으로 확정한다(이어하기 또는 명확히 처음부터 — 답안이 조용히 소실되지 않는 것이 원칙).

## Acceptance criteria

- [ ] 문항이 1개씩 노출되고, 선택 즉시 자동으로 다음 문항으로 넘어간다.
- [ ] 진행률이 정확히 표시된다.
- [ ] 직전 문항으로 돌아가 답을 바꿀 수 있고, 변경이 산출에 반영된다.
- [ ] 마지막 답안 후 결과 페이지로 자동 이동한다.
- [ ] 새로고침 정책이 정의된 대로 동작하며 답안이 조용히 사라지지 않는다.
- [ ] 디자인 시스템(03) 토큰/프리미티브를 따른다.
- [ ] agent-browser E2E로 12문항 완주 → 결과 도달이 확인된다.
