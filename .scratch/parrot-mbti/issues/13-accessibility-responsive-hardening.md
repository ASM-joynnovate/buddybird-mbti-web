# 13 · 접근성 & 반응형 하드닝

Status: ready-for-agent

## Parent

## What to build

전 구간에 걸친 **접근성·반응형·성능 하드닝** 패스. 각 UI 슬라이스가 기본 접근성은
이미 충족했다는 전제 하에, 교차 관심사를 마무리한다. 디자인 시스템(03)을 따른다.

- **키보드 조작**: 선택지·버튼·캐러셀·공유 등 전 플로우를 키보드만으로 완주할 수 있게 한다.
- **스크린리더**: 문항·선택지·진행률·결과·버튼이 의미 있게 읽히도록 시맨틱 마크업/레이블 정비.
- **자동 접근성 점검**을 통과한다(대비, 레이블, 역할 등).
- **반응형**: 320/375/768/1024/1440에서 오버플로 없이 의도대로 보이게 한다.
- **성능**: 마이크로사이트 성능 예산(빠른 FCP/LCP, 작은 번들)에 맞춘다 — 이미지 치수 명시, 렌더 블로킹 최소화, 레이아웃 시프트 방지.

## Acceptance criteria

- [ ] 안내→문항→결과→공유 전 플로우를 키보드만으로 완주할 수 있다.
- [ ] 스크린리더에서 문항·선택지·결과가 의미 있게 읽힌다.
- [ ] 자동 접근성 점검을 통과한다.
- [ ] 320/375/768/1024/1440에서 오버플로/깨짐이 없다(스크린샷 확인).
- [ ] 성능 예산을 충족한다(이미지 치수·시프트·블로킹 점검).
